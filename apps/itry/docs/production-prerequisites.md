# Production prerequisites

The prototype can be evaluated without external credentials. A real public beta needs:

1. A Supabase project explicitly dedicated to iTry (or explicit approval to share an existing project).
2. Production auth configuration and notification/email provider.
3. Approved catalog/affiliate accounts for external retailers.
4. A payment/direct-commerce provider for merchants that support Autopilot.
5. Merchant terms, refund/cancellation handling, tax/payment review, and privacy/legal review.
6. Production hosting/domain and deployment configuration.
7. Store/developer accounts when native iOS/Android clients are introduced.

These are integration/account prerequisites rather than unresolved product-discovery questions.
