# V1 scope

V1 targets accounts/profiles, accepted connections and private contacts, private relationship labels, common/custom occasions, giver budgets, recipient-owned preference signals, optional preference dashboard, learning controls, explainable physical-product recommendations, duplicate-risk warnings, private delivery capability, transaction attribution, and the Autopilot authorization/veto model where direct purchase is technically supported.

Experiences, group gifting, full merchant self-service, advanced merchant analytics, and native mobile apps follow after the core loop is validated.
