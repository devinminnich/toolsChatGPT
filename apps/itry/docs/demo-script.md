# iTry demo script

1. Open Home: the next important occasion is immediately visible.
2. Scroll to gift ideas: compare recommendations and the privacy-safe `Why it fits` explanation.
3. Inspect the coffee recommendation: note the possible-duplicate warning and ability to proceed manually.
4. Adjust the Autopilot ceiling: note that the ceiling is private and above-limit spend requires approval.
5. Open People: switch to another recipient and return to their occasion.
6. Open For me: show that inferred preferences belong to the recipient and can be corrected optionally.
7. Open Settings: pause learning and review the private-delivery concept.
8. Use the on-screen helper actions to demonstrate the lightweight preference feedback model.
9. For the browser extension proof of concept, load `apps/itry/extension` unpacked and deliberately save an active product page using one of the four preference actions.
