# iTry prototype release

This prototype is ready for product testing of the iTry concept. It is not a production commerce release.

## Testable now
- Responsive gifting dashboard
- Upcoming occasion flow
- Person switching
- Private budget presentation
- Explainable gift recommendations
- Duplicate-risk warning
- Autopilot limit/veto UX
- Optional private preference dashboard
- Pause/resume learning UX
- User-initiated Chrome/Edge gift-helper extension

## Requires production services before public launch
- Account authentication and live multi-user connections
- Dedicated iTry Supabase deployment
- Email/push notifications
- Live catalog/affiliate provider credentials
- Payment processor/direct merchant integration
- Real Autopilot purchase execution
- Production address encryption/fulfillment service
- Native iOS/Android applications

The repository includes the backend schema and architectural boundaries needed to begin those integrations without redesigning the prototype's core data/privacy model.
