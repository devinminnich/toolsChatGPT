# iTry roadmap

## Prototype — complete in repository
Responsive web concept, core interaction model, privacy boundaries, extension proof of concept, RLS-first schema, Autopilot safeguards, CI build workflow.

## Production foundation
Dedicated Supabase project; Auth; live connections/invites; private contacts; common/custom occasions; live per-connection settings; notifications.

## Recommendation service
Private preference aggregation; catalog-provider abstraction; relevance ranking; explainable recommendation output; duplicate-risk inference; delivery feasibility.

## Commerce
Affiliate attribution/external checkout first; direct participating merchants; private fulfillment; Autopilot veto and explicit approval; idempotent purchase execution.

## Expansion
Experiences/services, group gifting, merchant portal/analytics, native iOS/Android clients, additional retailer integrations.
